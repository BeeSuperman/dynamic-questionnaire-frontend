## 📌 一、產品概述

| 項目 | 說明 |
|------|------|
| **產品名稱** | 動態問卷系統（Dynamic Questionnaire） |
| **類比產品** | Google Forms、SurveyMonkey |
| **目標用戶** | 管理員（建立問卷）、一般使用者/訪客（填寫問卷） |
| **核心價值** | 讓管理員能快速建立各種問卷，使用者能方便填寫，管理員能即時查看統計結果 |

## 🔄 三、流程圖（Flowchart）— 使用者的操作路徑

### 3.1 管理員的完整操作流程

```mermaid
flowchart TD
    A[管理員打開系統] --> B{是否已登入?}
    B -->|否| C[登入頁面]
    C --> D[輸入 Email + 密碼]
    D --> E{驗證成功?}
    E -->|否| F[顯示錯誤訊息]
    F --> D
    E -->|是| G[進入後台問卷列表]
    B -->|是| G

    G --> H{要做什麼?}

    H -->|新增| I[點擊 + 新增按鈕]
    I --> J[填寫問卷資訊<br/>標題/描述/日期]
    J --> K[添加問題<br/>設定題型/選項/必填]
    K --> L[預覽確認]
    L --> M{發佈還是存草稿?}
    M -->|存草稿| N["存為未發佈<br/>(published=false)"]
    M -->|發佈| O["直接發佈<br/>(published=true)"]
    N --> G
    O --> G

    H -->|編輯| P[點擊問卷名稱]
    P --> Q{問卷狀態?}
    Q -->|未發佈/未開始| R[進入編輯頁面<br/>可修改所有內容]
    Q -->|進行中/已結束| S["⚠️ 提示: 不可修改<br/>跳轉至統計頁面"]
    R --> L

    H -->|刪除| T[勾選問卷]
    T --> U[點擊刪除按鈕]
    U --> V{確認刪除?}
    V -->|取消| G
    V -->|確定| W[刪除問卷+問題]
    W --> G

    H -->|查看回饋| X[點擊前往按鈕]
    X --> Y[查看填寫者列表<br/>+統計圖表]

    H -->|修改資料| Z[進入會員資料頁]
    Z --> AA[修改姓名/電話/密碼]
    AA --> G

    style N fill:#f9f,stroke:#333
    style O fill:#9f9,stroke:#333
    style S fill:#ff9,stroke:#333
```

### 3.2 使用者/訪客的填寫流程

```mermaid
flowchart TD
    A[使用者打開系統] --> B[看到問卷列表<br/>只有已發佈的問卷]
    B --> C{想做什麼?}

    C -->|搜尋| D[輸入標題/日期]
    D --> E[過濾後的列表]
    E --> C

    C -->|填寫問卷| F[點擊問卷名稱]
    F --> G{問卷狀態?}
    G -->|尚未開始| H["⚠️ 還不能填寫"]
    G -->|已結束| I[只能查看統計圖表]
    G -->|進行中 ✅| J[進入填寫頁面]

    J --> K[填寫個人資訊<br/>姓名/Email/手機/年齡]
    K --> L[回答各問題<br/>單選/多選/簡答]
    L --> M[點擊送出]

    M --> N{驗證通過?}
    N -->|必填未填| O["⚠️ 請填寫必填項目"]
    O --> L
    N -->|Email重複| P["⚠️ 此Email已填過"]
    P --> L
    N -->|年齡≤18| PP["⚠️ 年齡必須大於18"]
    PP --> L
    N -->|通過 ✅| Q[跳轉到確認頁]

    Q --> R[預覽所有填寫內容]
    R --> S{確認無誤?}
    S -->|返回修改| J
    S -->|確認送出| T{是否為註冊會員?}

    T -->|是會員| U["提示: 個人資料不會被覆蓋<br/>僅保存答案"]
    T -->|是訪客| V[自動建立User記錄<br/>password=null]
    U --> W[資料寫入資料庫]
    V --> W
    W --> X["✅ 送出成功！<br/>跳回問卷列表"]

    C -->|查看統計| Y[點擊統計按鈕]
    Y --> I

    style H fill:#ff9,stroke:#333
    style P fill:#f99,stroke:#333
    style X fill:#9f9,stroke:#333
```

### 3.3 會員系統流程

```mermaid
flowchart TD
    A[使用者] --> B{有帳號嗎?}

    B -->|沒有| C[點擊註冊]
    C --> D[填寫 Email/姓名/密碼/手機]
    D --> E{驗證}
    E -->|Email已存在| F["⚠️ 此信箱已被註冊"]
    F --> D
    E -->|密碼不符規範| G["⚠️ 密碼須8-12字"]
    G --> D
    E -->|通過| H["密碼用 BCrypt 加密後存入DB"]
    H --> I["✅ 註冊成功<br/>跳轉登入頁"]

    B -->|有| J[點擊登入]
    J --> K[輸入 Email + 密碼]
    K --> L{後端驗證}
    L -->|帳號不存在| M["⚠️ 帳號或密碼錯誤"]
    L -->|密碼錯誤| M
    M --> K
    L -->|成功| N{是管理員嗎?}
    N -->|Email以admin開頭| O[跳轉後台列表]
    N -->|一般用戶| P[跳轉前台列表]

    O --> Q{要修改資料?}
    P --> Q
    Q -->|是| R[進入會員資料頁]
    R --> S[修改姓名/電話/密碼]
    S --> T["新密碼重新 BCrypt 加密"]
    T --> U["✅ 更新成功"]

    Q -->|登出| V[清除 sessionStorage]
    V --> J

    style H fill:#9cf,stroke:#333
    style I fill:#9f9,stroke:#333
    style U fill:#9f9,stroke:#333
```
